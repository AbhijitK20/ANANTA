## 2026-09-26 `relax` takes a `pool` this stage never supplies, so the ladder cannot refill

- symptom: session 6's `relax(stops, ctx, cause, options)` accepts `{ pool }`, documented as "Records to draw from when refilling. I have noted it in the `walkLadder` doc comment rather than adding a parameter nothing calls. If session 6 wants the ladder to refill, add an optional `pool` to `walkLadder` and I will pass the same candidates in.
