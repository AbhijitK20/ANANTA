# Accessibility Requirements

- Full keyboard navigation.
- Visible focus states.
- Semantic headings and form labels.
- Screen-reader-friendly controls.
- Minimum readable contrast.
- Do not use color alone for status.
- Touch targets suitable for mobile.
- Clear validation and error messages.
- Text/list alternative for every map result.
- Experience accessibility metadata visible in the detail page.
- Reduced-motion support where animation exists.
- Plain language for recommendations and warnings.
