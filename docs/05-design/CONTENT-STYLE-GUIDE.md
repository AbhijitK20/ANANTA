# Content Style Guide

## Voice

Use clear, useful, grounded language. The product should sound like a knowledgeable local guide, not an AI assistant making grand promises.

## Rules

- State what the system knows and how recently it was checked.
- Prefer exact facts over hype.
- Keep cards concise.
- Explain recommendations using actual signals.
- Distinguish verified facts from creator perspective.
- Do not invent reviews, metrics, quotes, prices, or availability.
- Do not use emoji in interface labels or system messages.
- Do not use em dashes in product copy.

## Examples

| Avoid | Use |
|---|---|
| Discover the magic of Mumbai | Explore verified experiences near you |
| Perfect for everyone | Suitable for families with children aged 6+ |
| Always available | Availability confirmed at 3:10 PM |
| Loved by thousands | 4.6 rating from 28 verified reviews |
| Hidden gem | Community-recommended, less crowded experience |
| Book now | Check availability |

## Status Language

- `Verified by provider`
- `Official venue listing`
- `Community reported`
- `Availability needs confirmation`
- `Hours checked 2 days ago`
- `Video may not reflect current details`
- `No verified events match this time window`
