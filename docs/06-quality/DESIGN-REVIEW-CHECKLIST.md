# Design Review Checklist

Run this checklist before approving any screen or reusable component.

## Visual

- [ ] No purple gradient.
- [ ] No default pill-shaped buttons.
- [ ] No emoji icons.
- [ ] No glassmorphism or generic AI decoration.
- [ ] Royal blue is used intentionally, not everywhere.
- [ ] Typography hierarchy is clear.
- [ ] Button shapes and spacing match the design tokens.
- [ ] No excessive animation.

## Content

- [ ] Headline describes a real capability.
- [ ] No vague hero text.
- [ ] No AI filler copy.
- [ ] No em dashes.
- [ ] Empty states are honest.
- [ ] Metrics, ratings, reviews, and testimonials are real or absent.

## Media

- [ ] Images are real, licensed, provider-submitted, or clearly labeled placeholders.
- [ ] External videos include source and creator attribution.
- [ ] Media does not claim current facts without structured verification.
- [ ] Broken media has an external-link or unavailable fallback.

## Product Truth

- [ ] Availability is not fabricated.
- [ ] Price is not fabricated.
- [ ] Recommendation explanation uses actual signals.
- [ ] Trust and freshness information is visible where relevant.
- [ ] Booking language matches whether booking is real or simulated.

## Accessibility and Responsive Behavior

- [ ] Keyboard focus is visible.
- [ ] Color is not the only status signal.
- [ ] Map has list fallback.
- [ ] Mobile width has no horizontal overflow.
- [ ] Reduced motion is respected.
