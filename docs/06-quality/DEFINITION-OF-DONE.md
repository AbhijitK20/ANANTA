# Definition of Done

A backlog item is Done only when:

- Acceptance criteria pass.
- Required backend and UI behavior exists.
- Validation and authorization are implemented.
- Loading, empty, and error states exist.
- Responsive behavior is checked.
- Accessibility basics are checked.
- Relevant unit, integration, or end-to-end test exists.
- External failures have a fallback.
- Data provenance and freshness are preserved where relevant.
- No secrets are committed.
- Code and documentation are reviewed.
- The item works in the target demo flow.
- The design review checklist passes for user-facing changes.
- User-facing copy contains no fabricated claim, prohibited pattern, emoji icon, or em dash.
- Legal links and required metadata exist for public-facing pages.
