# External Media Policy

## Purpose

External videos help travelers understand atmosphere and context before visiting. They are not the source of current operational truth.

## Supported Media

- YouTube videos and Shorts
- Instagram Reels where embedding or linking is permitted
- Provider videos
- Official venue videos
- Local creator videos
- Community-submitted media

## Storage

Store:

- External URL
- Platform and external ID
- Title and thumbnail reference where permitted
- Creator/channel name
- Publish date
- Duration where available
- Media type
- Verification state
- Last checked time

Do not download or re-host third-party video files.

## Review

Before publishing, verify:

1. The video shows the correct place or event.
2. The source is public and attributable.
3. Embed or link behavior is permitted.
4. The video is still available.
5. The video is not misleading, unsafe, or inappropriate.
6. Old content is labeled when current conditions may differ.

## Fallback

If an embed fails, show a static thumbnail and `Open on YouTube` or `Open on Instagram`. If the source is deleted, private, unavailable, or misleading, archive it.

## Truth Boundary

```text
External video → atmosphere and context
Structured record → price, hours, availability, accessibility, safety, and booking truth
```
